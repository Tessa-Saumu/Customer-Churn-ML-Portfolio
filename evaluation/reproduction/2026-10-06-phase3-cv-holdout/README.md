## Protocol this log records (Phase 3, audit item FGA-05)

- Outer stratified 80/20 split, `random_state=42` → 5,634 training rows, 1,409 holdout
  rows. The holdout is frozen until the winner is chosen.
- 5-fold `StratifiedKFold(shuffle=True, random_state=42)` over the training portion
  only, with the preprocessor refit inside every fold. Selection criterion: mean fold
  ROC AUC (unchanged criterion, moved off the holdout).
- Candidates: Logistic Regression (`max_iter=1000`), Decision Tree, Random Forest,
  XGBoost, LightGBM — all `random_state=42`, default hyperparameters, no tuning.
- Baseline: `DummyClassifier(strategy="prior")`, scored in the same folds, never
  eligible for selection.
- Winner refitted on the full training portion, then the winner and the baseline are
  evaluated once on the untouched holdout.

Result: **Logistic Regression** selected again (mean CV ROC AUC 0.8591, fold
std 0.0142); untouched-holdout accuracy 0.7991 / precision 0.6435 / recall 0.5455 /
ROC AUC 0.8496; baseline ROC AUC 0.5.
